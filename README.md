## Учебный проект: Модель банковского приложения
Этот проект представляет собой упрощённую модель банковского приложения, разработанную для закрепления знаний по работе с библиотеками pandas, logging, re, requests, API, datetime, а также для практики написания тестов с использованием pytest. Проект включает в себя обработку финансовых данных, логирование, работу с внешними API и генерацию отчётов.

### Структура проекта
Основные пакеты и файлы
data/:

operations.xlsx — основной файл с данными о транзакциях, с которым работает проект.

src/:

constants.py — содержит константы, настройки и загрузку данных.

decorators.py — реализация декораторов для записи результатов в JSON-файлы.

reports.py — функции для генерации отчётов по транзакциям.

services.py — функции для поиска транзакций и работы с API.

utils.py — вспомогательные функции, такие как приветствие, чтение данных по картам и получение актуальных курсов валют и акций.

views.py — основная логика для отображения данных на главной странице.

tests/:

Тесты для всех функций проекта, написанные с использованием pytest.

main.py:

Главный скрипт, который запускает приложение и предоставляет доступ ко всем функциям.

logs/:

Папка для хранения логов и JSON-отчётов, создаваемых в процессе работы приложения.

Установка и запуск
1. Клонирование репозитория

        git clone https://github.com/daniel-ocean97/CoursePaper1.git
        cd CoursePaper1
2. Установка зависимостей:
Для работы проекта необходимо установить зависимости, указанные в файле requirements.txt. Если файла нет, установите следующие библиотеки:

        pip install pandas requests python-dotenv openpyxl pytest
3. Настройка окружения:
Создайте файл .env в корневой директории проекта и добавьте в него API-ключи(пример находится в файле .env.template):

Убедитесь, что файл operations.xlsx находится в папке data/.

4. Запуск проекта:
Запустите главный скрипт:


    python main.py
## Функциональность проекта
### Основные возможности
#### Главная страница:

Отображает приветствие в зависимости от времени суток.

Показывает информацию о расходах по картам за текущий месяц.

Отображает топ-5 транзакций за указанный период.

Показывает актуальные курсы валют и цены на акции.

Поиск транзакций по номеру телефона:

Ищет транзакции, в описании которых указан номер телефона.

#### Отчёты по категориям:

Генерирует отчёт по транзакциям за последние 3 месяца для указанной категории.

Результат можно сохранить в JSON-файл.

#### Логирование:

Все действия логируются в файлы, расположенные в папке logs/.

#### Тестирование:

В папке tests/ реализованы тесты для всех функций проекта.
